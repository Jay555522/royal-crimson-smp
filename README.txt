THE ROYAL CRIMSON SMP WEBSITE
===============================

Pages:
- index.html: homepage, community information, groups, rules, joining, social links, and gallery
- reigm-empire.html: dedicated Reigm Empire profile
- zephyrial-empire.html: dedicated Zephyrial Empire profile
- endoria.html: dedicated Endoria profile
- security-team.html: dedicated Royal SMP Security Team profile
- style.css: responsive website design
- script.js: mobile navigation and current footer year
- images/: supplied Minecraft screenshots and official flags/banners

PREVIEW:
Open index.html in a web browser. Use the group links on the homepage or navigation to open each separate profile page.

PUBLISHING:
This is a static website and can be hosted free with GitHub Pages. Create a GitHub repository, upload these files, then enable GitHub Pages in Settings > Pages.

NOTES:
- Group profiles use confirmed details; unknown information is not invented.
- No server IP, port, phone number, email, or private contact details are included.
- Account creation, photo uploads, and group chat are not implemented in this static version.
